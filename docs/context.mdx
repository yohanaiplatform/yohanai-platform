# Project Context

## Product Identity

Yohan.AI adalah **Property Buyer Behavior Intelligence Platform**.

Platform ini membantu agen properti memahami perilaku calon pembeli, mengelola hubungan dengan pelanggan, mengotomatisasi komunikasi, dan meningkatkan conversion rate menggunakan Artificial Intelligence.

WhatsApp hanyalah salah satu channel komunikasi, bukan produk utama.

# Quality Gate

Sebelum merge wajib memenuhi:

- TypeScript PASS
- ESLint PASS
- Production Build PASS
- Runtime QA PASS
- Architecture Review PASS

Jika salah satu gagal, task dianggap belum selesai.

---

# Coding Rules

- Jangan hardcode schema database.
- Gunakan helper untuk business logic.
- Component hanya bertanggung jawab terhadap UI.
- Hindari duplicate code.
- Semua feature harus modular.
- Gunakan Server Component bila memungkinkan.

# AI Roles

Sejak Agustus 2026 seluruh implementasi dikerjakan dengan **Claude Code**, menggantikan pembagian peran ChatGPT dan Qwen pada fase awal project. Dokumen arsip dari era tersebut ada di `project-docs/` dan bersifat historis saja.

Claude Code bertanggung jawab untuk:

- Implementation, refactoring, dan bug fixing
- Technical review dan quality assurance
- Migration database
- Pemeliharaan dokumentasi

Keputusan produk, arsitektur tingkat tinggi, dan prioritas tetap di tangan Yohan.

---

# Documentation Strategy

Mintlify adalah **Single Source of Truth** untuk seluruh dokumentasi proyek, dipublikasikan di `docs.yohanai.id`. Sumbernya adalah berkas `.mdx` di folder `docs/` pada repository ini — push ke `main` otomatis men-deploy Vercel dan Mintlify sekaligus.

Satu pengecualian: `AGENTS.md` di root repository. Berkas itu bukan dokumentasi produk melainkan konteks teknis yang dibaca otomatis oleh AI setiap memulai sesi, sehingga harus tetap berada di root.

---

# Session Rule

Setiap memulai sesi baru, AI wajib membaca:

1. `AGENTS.md` di root repository
2. Project Context
3. Project Status

Tidak perlu membuat dokumen handoff baru setiap pindah sesi. Perbarui ketiga dokumen di atas.

Setelah itu langsung melanjutkan task tanpa investigasi ulang yang tidak diperlukan.
