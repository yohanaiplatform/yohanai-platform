# Migration Blueprint

## Executive Summary

Yohan.AI adalah proyek migrasi dari Google Workspace menuju platform
modern berbasis Next.js 16 + Supabase PostgreSQL. Strategi migrasi
menggunakan **Progressive Migration** sehingga sistem legacy tetap aktif
sampai seluruh modul tervalidasi.

## Legacy Architecture

``` text
Google Form
      ↓
Google Spreadsheet
      ↓
Google Apps Script
      ↓
Google Apps Script API
      ↓
WAHA / n8n
      ↓
CRM & Dashboard
```

## Target Architecture

``` text
Next.js
    ↓
Supabase PostgreSQL
    ↓
API Route
    ↓
AI Engine
    ↓
Dashboard
```

## Legacy Assets

### Spreadsheet

-   CRM Database
-   Listing Database
-   Listing Inbox
-   Chat Log
-   System Config

### Apps Script

-   AI Processor
-   Decision Engine
-   CRM Engine
-   Dashboard
-   Automation

### Google API

-   Customer API
-   Inbox API
-   Chat Log API
-   AI Update API

## Database Mapping

Nama tabel di bawah sudah diselaraskan dengan skema yang benar-benar ada di Supabase (diverifikasi 23 September 2026). Versi sebelumnya memetakan ke nama datar seperti `customers` dan `inquiries` yang tidak pernah ada — database memakai schema terpisah per domain.

| Legacy | Supabase |
|--------|----------|
| Input Data | `customer.leads` |
| Listing | `property.listings` |
| Listing Inbox | `customer.leads` (dibedakan lewat `lead_source_id`) |
| Chat Log | `chat.conversations` + `chat.messages` |
| AI Queue | `ai.prompts` |
| AI Analysis | `ai.interactions` |
| Config | `core.settings` |

## API Mapping

Belum ada satu pun yang dibangun. Route yang eksis saat ini hanya `/api/health`.

| Legacy API | Next.js API | Status |
|------------|-------------|--------|
| createInboxLead | `/api/leads/intake` | 🔵 Rencana — lihat Rencana Lead Intake di halaman CRM Module |
| customer, createCustomer | `/api/leads` | 🔵 Rencana |
| createChatLog | `/api/chatlogs` | 🔵 Rencana |
| updateCustomerAI | `/api/ai/leads` | 🔵 Rencana |

## Migration Strategy

-   Progressive Migration
-   Blue-Green Deployment
-   Parallel Validation
-   Rollback Ready
-   Zero Data Loss

## Current Sprint

Selesai: Infrastructure, Supabase Foundation, Database Schema, ERD.

Berikutnya: Lead Intake dari Google Form, lalu CRM Foundation dan AI Foundation.

Catatan penting sebelum migrasi dilanjutkan: **Apps Script legacy bukan sekadar pemindah data.** Di dalamnya ada AI Processor, Decision Engine, dan CRM Engine — logika bisnis yang perlu dipahami dan diputuskan nasibnya satu per satu, bukan diterjemahkan membabi buta ke kode baru.
