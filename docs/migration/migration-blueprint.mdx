# Migration Blueprint

## Executive Summary

Yohan.AI adalah proyek migrasi dari Google Workspace menuju platform
modern berbasis Next.js 16 + Supabase PostgreSQL. Strategi migrasi
menggunakan **Progressive Migration** sehingga sistem legacy tetap aktif
sampai seluruh modul tervalidasi.

## Legacy Architecture

``` text
Google Form
      ↓
Google Spreadsheet
      ↓
Google Apps Script
      ↓
Google Apps Script API
      ↓
WAHA / n8n
      ↓
CRM & Dashboard
```

## Target Architecture

``` text
Next.js
    ↓
Supabase PostgreSQL
    ↓
API Route
    ↓
AI Engine
    ↓
Dashboard
```

## Legacy Assets

### Spreadsheet

-   CRM Database
-   Listing Database
-   Listing Inbox
-   Chat Log
-   System Config

### Apps Script

-   AI Processor
-   Decision Engine
-   CRM Engine
-   Dashboard
-   Automation

### Google API

-   Customer API
-   Inbox API
-   Chat Log API
-   AI Update API

## Database Mapping

Nama tabel di bawah sudah diselaraskan dengan skema yang benar-benar ada di Supabase (diverifikasi 23 September 2026). Versi sebelumnya memetakan ke nama datar seperti `customers` dan `inquiries` yang tidak pernah ada — database memakai schema terpisah per domain.

| Legacy | Supabase |
|--------|----------|
| Input Data | `customer.leads` |
| Listing | `property.listings` |
| Listing Inbox | `customer.leads` (dibedakan lewat `lead_source_id`) |
| Chat Log | `chat.conversations` + `chat.messages` |
| AI Queue | `ai.prompts` |
| AI Analysis | `ai.interactions` |
| Config | `core.settings` |

## API Mapping

| Legacy API | Next.js API | Status |
|------------|-------------|--------|
| createInboxLead | `POST /api/leads/intake` | ✅ Selesai, terverifikasi end-to-end di production (23 Sep 2026) — lihat "Rencana Lead Intake" di halaman CRM Module |
| customer, createCustomer | `/api/leads` | 🔵 Rencana |
| createChatLog | `POST /api/whatsapp/webhook` + `POST /api/whatsapp/send` | ✅ Selesai (Kapso sandbox, 26 Sep 2026) — beda jalur dari rencana awal (`/api/chatlogs`), langsung terhubung ke `chat.conversations`/`chat.messages` |
| updateCustomerAI | `/api/ai/leads` | 🔵 Rencana |
| — | `GET /api/health` | ✅ Selesai (health check) |

## Migration Strategy

-   Progressive Migration
-   Blue-Green Deployment
-   Parallel Validation
-   Rollback Ready
-   Zero Data Loss

## Current Sprint

Selesai: Infrastructure, Supabase Foundation, Database Schema, ERD, **Lead Intake dari Google Form (Fase 1)**, **CRM Foundation (Fase 2)**, **Communication Automation (Kapso, sandbox)**, **Property Module (Fase 1)** — semua live per 26 September 2026.

Keputusan Communication Automation sudah diambil: **Kapso** (BSP resmi WhatsApp Cloud API Meta), bukan WAHA/Fonnte — lihat "WAHA / n8n" di diagram Legacy Architecture di bawah, itu peran yang sekarang digantikan Kapso untuk arsitektur baru. Kirim/terima pesan + live chat sudah jalan di sandbox Kapso; nomor produksi (Griya Indonesia Real Estate) sengaja belum disambungkan.

Berikutnya (disepakati eksplisit bareng Yohan 26 Sep 2026): (1) AI Agent / Intelligent Dashboard, (2) alur dokumen tanda tangan untuk lead closing (spreadsheet + Apps Script dari sesi terpisah), (3) baru sambungkan nomor WhatsApp produksi.

Catatan penting: **Apps Script legacy bukan sekadar pemindah data.** AI Processor, Decision Engine, dan CRM Engine di dalamnya sengaja TIDAK ikut dipindahkan ke `customer.leads` — hanya field mentah (input form) yang dikirim lewat `POST /api/leads/intake`. Detail pemetaan kolom mana yang mentah vs hasil AI ada di `docs/modules/crm.mdx`.
