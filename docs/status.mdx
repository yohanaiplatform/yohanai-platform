## Priority 1

Authentication Stabilization — Selesai secara teknis, Facebook Login menunggu approval Meta

Target:

- Google OAuth Login & Register — ✅ Confirmed jalan di production
- Forgot Password — ✅ Fixed & confirmed (kini via Resend SMTP, sebelumnya Gmail App Password)
- Register (email) & Email Verification — ✅ Confirmed jalan end-to-end
- Profile Page dummy data — ✅ Fixed, fetch data real dari `auth_ext.profiles`
- Facebook Login — ✅ Berfungsi secara teknis (tombol di Login & Register, provider dikonfigurasi benar, berhasil login & auto-linked ke akun existing berdasarkan email). App masih **Unpublished**, menunggu **Meta Business Verification** (status: **In Review**).
- Meta Business Verification — Sempat ditolak dengan alasan nama legal usaha tidak muncul di website. Diperbaiki dengan menambahkan nama legal (Yohan Benyamin Betty, NIB: 1709210039303) ke Footer dan halaman Privacy Policy. Sudah di-resubmit ke Meta, saat ini berstatus **In Review**.
- Domain Verification untuk Facebook — ✅ Selesai (`facebook-domain-verification` meta tag di `layout.tsx`)
- Privacy Policy & Data Deletion pages — ✅ Dibuat, sekarang juga mencantumkan nama legal usaha
- Email domain `@yohanai.id` — ✅ Fixed. Root cause: domain `yohanai.id` (DNS dikelola Cloudflare, terhubung ke Vercel untuk web) tidak punya **MX Record** sama sekali, sehingga semua email masuk ke `admin@yohanai.id` (termasuk kode verifikasi Meta) tidak pernah sampai. MX Record ditambahkan mengarah ke `pangulubao.iixcp.rumahweb.net`, terverifikasi jalan via MXToolbox dan email masuk sukses diterima.
- **SMTP outbound (auth emails)** — ✅ Migrasi dari Gmail personal ke **Resend**. Password SMTP `admin@yohanai.id` di cPanel juga sudah diperbaiki sebagai langkah awal sebelum migrasi. Domain `yohanai.id` diverifikasi di Resend dengan subdomain khusus `send.yohanai.id` (memakai MX & TXT terpisah), sehingga email masuk existing di `yohanai.id` (via rumahweb) tidak terganggu. Supabase Authentication → SMTP Settings sudah dikonfigurasi ke `smtp.resend.com` (port 465). Tested end-to-end via flow Forgot Password — email diterima langsung di Focused Inbox (bukan Spam) pada percobaan pertama.
- **SPF, DKIM, DMARC untuk `yohanai.id`** — ✅ Selesai. SPF & DKIM ter-setup otomatis lewat proses verifikasi domain Resend (`send.yohanai.id`). DMARC record (`_dmarc.yohanai.id`, `v=DMARC1; p=none`) ditambahkan manual di Cloudflare, mode monitoring (`p=none`) untuk tahap awal.
- **Supabase Free Tier auto-pause mitigation** — ✅ Selesai. Dibuat GitHub Actions scheduled workflow (`.github/workflows/supabase-keepalive.yml`) yang ping endpoint `/auth/v1/admin/users` (pakai `service_role` key) tiap 3 hari untuk reset timer inactivity Supabase (batas asli: 7 hari tanpa aktivitas query database). Workflow juga fail eksplisit + kirim notifikasi GitHub kalau ping gagal, bukan silent fail.

Semua menggunakan data Supabase.
